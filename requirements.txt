# Deep-learning framework note
# ---------------------------
# This project uses PyTorch rather than TensorFlow/Keras. On the target platform
# (Windows + Python 3.13) TensorFlow has no GPU support at all: native-Windows
# GPU builds stopped at TF 2.10, which requires Python <= 3.10. PyTorch's CUDA
# wheels work on this configuration and were verified against the GTX 1650 in
# the development environment. The architecture is framework-agnostic: all model
# code lives in backend/app/ml/ and is shared by training and serving.
#
# Install torch first, from the index matching your CUDA version:
#   pip install --index-url https://download.pytorch.org/whl/cu126 torch torchvision
# For CPU-only:
#   pip install --index-url https://download.pytorch.org/whl/cpu torch torchvision
